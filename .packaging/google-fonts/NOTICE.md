# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at 7af0d90b4d532ffa4b041937b560c6df4e7b1e95.

- Fredoka: OFL-1.1 (google/fonts `ofl/fredoka/OFL.txt`)
- Nunito: OFL-1.1 (google/fonts `ofl/nunito/OFL.txt`)

Source stylesheets:

- `https://fonts.googleapis.com/css2?family=Fredoka:wght@500;600;700&family=Nunito:wght@600;700;800;900&display=swap` (sha256 cbac6102941acf7dd92329c83f9eb1fa18d9ded6e76a2c41e347e4e8af04af26)
